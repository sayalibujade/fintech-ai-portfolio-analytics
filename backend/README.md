# AI Trading Dashboard - Node.js Backend

This directory contains the enterprise-ready Express 5 API layer, domain routing logic, Google Gemini integration, and MongoDB multi-document transaction controls.

## 🚀 Development Tasks
* **Install Dependencies:** `npm install`
* **Local Development Run:** `npm run dev`
* **Production Build Compilation:** `npm run build`
* **Execution Metrics Matrix (Jest):** `npm run test`

For the full architectural breakdown, system design diagrams, and frontend setup instructions, please refer to the primary [Root README](../README.md).
