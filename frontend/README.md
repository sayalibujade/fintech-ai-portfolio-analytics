# AI Trading Dashboard - Angular Frontend

This directory contains the decoupled UI presentation layer for the AI Trading Dashboard application, built with Angular 22 and NgRx Signals.

## 🚀 Development Tasks
* **Install Dependencies:** `npm install`
* **Local Dev Server:** `npm start` (runs at `http://localhost:4200`)
* **Production Build:** `npm run build`
* **Test Strategy Coverage:** `npm run test`

For the full architectural breakdown, system design diagrams, and backend setup instructions, please refer to the primary [Root README](../README.md).
